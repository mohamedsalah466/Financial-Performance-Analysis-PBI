# Financial Performance Dashboard | Power BI

## Project Overview

This Power BI dashboard analyzes financial performance focusing on revenue, cost, profitability, operating income, and business efficiency.

The dashboard helps monitor financial KPIs, evaluate trends over time, and support strategic decision-making.

---

## Tools & Technologies Used

- Power BI
- DAX Measures
- Power Query
- Data Modeling
- KPI Development
- What-If Parameter Analysis
- Drill Through
- Financial Analytics

---

## Dashboard Pages

### 1- Revenue, Cost & Gross Margin Analysis

Analyzes:

- Total Revenue
- Total Cost
- Gross Margin (GM)
- GM%
- Revenue trend by month
- Cost trend by month
- Profitability by category
- Supplier performance

---

### 2- Income Statement Dashboard

Analyzes:

- Revenue
- Expenses
- Operating Income
- Operating Margin %
- Monthly performance
- Financial statement breakdown

---

### 3- Drill Through Analysis

Provides detailed investigation into:

- MOM Revenue changes
- MOM Cost changes
- MOM Gross Margin
- Team performance
- Supervisor performance
- Salesperson contribution

---

### 4- Financial Simulator (What If Analysis)

Allows simulation of:

- Price changes
- Quantity changes
- Cost changes
- Expense changes

Measures impact on:

- Revenue
- Cost
- Operating Income
- Profitability

---

## Key Insights

- Revenue and cost fluctuate over time affecting profitability.
- Gross margin varies across suppliers and product categories.
- Operational efficiency directly impacts operating income.
- What-if scenarios help estimate future financial outcomes.

---

## Business Recommendations

- Reduce high operational costs.
- Improve low-performing categories.
- Focus on profitable suppliers.
- Use scenario analysis before strategic decisions.
